# Проста версія — як грати й що далі

## Запуск

```bash
npm run build    # збирає dist/novobranets.html
open dist/novobranets.html   # macOS; на інших ОС — просто відкрити файл у браузері
npm test
npm run sim
```

`dist/` не зберігається в git: це результат збірки. Один файл (~300 KB), без сервера й інтернету — можна надіслати в месенджер або покласти на будь-який хостинг.

## Що вміє ця версія

- 76 карток, 9 фіналів, 6 показників, 4 навички, 5 фаз.
- Авторський текст наслідку для кожного з 228 виборів.
- Картки пам'ятають твої рішення (echo): рядок-спогад з'являється, якщо вчинок справді був.
- Заблоковані варіанти пояснюють, чого не вистачає («потрібно: навичка «Люди» ≥ 1»).
- Перший нуль здоров'я — тебе виносять; вдруге — кінець.
- Після фіналу: «Прожити ще раз» (новий seed) і «Той самий світ — інші рішення» (той самий seed, а на картках видно, що ти обрав минулого разу, і де саме розійшовся).
- Мобільний екран від 360 px, без встановлення.

## Куди розширювати

1. **Контент**: `data/test-content.ts`; валідатор і `npm test` скажуть, якщо щось не так.
2. **Епітафія від гравця**: після фіналу — шаблони + власний текст (локально).
3. **Книга пам'яті**: список минулих забігів у `localStorage`.
4. **Метапрогресія**: розширення набору варіантів між забігами (не сили героя).
5. **Бекенд** — лише коли є що синхронізувати (спільна статистика, модерація текстів).
