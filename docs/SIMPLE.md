# Проста версія — як грати й що далі

## Запуск

```bash
npm run play     # збірка + відкриває гру в браузері
npm run build    # тільки dist/novobranets.html
npm test         # автотести двигуна
npm run sim      # баланс-симуляція
```

`dist/novobranets.html` — один файл, 75 KB, без сервера й без інтернету. Його можна надіслати в месенджер, відкрити з телефона, покласти на будь-який хостинг.

## Що вміє ця версія

- 32 картки, 8 фіналів, 6 показників, 4 навички, 5 фаз.
- Варіанти, закриті умовами, показані сірим із підказкою — щоб було видно, що шлях існує.
- «Директор долі»: до дня 20 смерть лише від власних помилок, після 30-го шанс зростає, на 60-му — жорсткий кінець.
- Після фіналу: «Прожити ще раз» (новий seed) і «Той самий шлях» (той самий seed — видно, де рішення розійшлися).
- Мобільний екран від 360 px, без встановлення.

## Куди розширювати (у порядку користі)

1. **Контент**: 32 → 80 карток. Це найбільша робота і найбільший ефект не дає ніщо інше. Формат — `data/test-content.ts`, валідатор перевірить.
2. **Епітафія від гравця**: після фіналу — вибір із 3 шаблонів + опційний свій текст (локально).
3. **Книга пам'яті**: список минулих забігів у `localStorage` (епітафія, день, фінал).
4. **Метапрогресія**: рівні навичок переносяться між забігами.
5. **Бекенд** — лише коли є що синхронізувати (спільна статистика, модерація текстів).

## Чого тут свідомо немає

Акаунтів, бекенду, аналітики, звуку, локалізації EN. Усе це — після того, як гра доведе, що в неї хочеться грати вдруге.
