# «Новобранець» — прототип двигуна

Двигун забігу без UI. Мета — перевірити головну гіпотезу ТЗ: **чи цікаво грати, коли фінал відомий наперед**.

## Запуск

```bash
npm test        # 20 тестів
npm run sim     # баланс: 5 стилів гри, розподіл днів, рішень, фіналів
node --experimental-strip-types scripts/validate.ts   # перевірка контенту
```

## Що всередині

```
src/types.ts        типи: показники, навички, картки, echo, фінали, конфіг директора
src/rng.ts          детермінований PRNG (mulberry32) — забіг відтворюється за seed
src/conditions.ts   умови, ефекти (затискання 0..10), describeRequirement для підказок
src/run.ts          ядро: draw/choose, фази, директор долі, порятунок, вибір фіналу
src/validate.ts     валідатор: дублі, мертві прапорці й echo, замкнені навички, ланцюги
data/test-content.ts 76 карток, 9 фіналів, авторські наслідки для всіх 228 варіантів
scripts/simulate.ts  симулятор + звіт про недосяжні фінали
test/                20 тестів
web/                 UI (index.html + app.js), збирається в dist/novobranets.html
```

## Правила, вшиті в код

| Правило | Чому |
|---|---|
| Детермінований seed | баг і забіг відтворюються, аналітика чесна |
| Доля кидає кубик **раз на добу** (в `advanceTime`), не на картку | інакше ризик залежить від того, скільки карток випало за день |
| `inevitability` — реальний множник ризику (+1,2% за день після дня 30) | «лічильник неминучості» з ТЗ має впливати, а не прикрашати |
| Безпечно до дня 20, жорстко на дні 60 | темп фази 5 (було 90 у ТЗ) |
| Перший нуль здоров'я — «тебе виносять» (здоров'я 2, прапорець `carried_out`), другий — кінець | смерть має бути сценою, а не помилкою шкали |
| Фінал залежить від причини **і** від шляху: заслужені фінали (прапорці, високі показники) важать ×2 | колись «доля» могла дати лише accident-фінали, і п'ять із дев'яти були недосяжні |
| Вікно пам'яті 4 картки + квадратичне здешевлення повторів | одна «сумка» тричі поспіль — це нудьга |
| `echo` лише додає рядок-спогад, але не вмикає й не вимикає картку | раніше картки з echo зникали, поки не було сліду |
| Мертвий прапорець, мертвий echo або замкнена навичка = помилка валідації | недосяжний контент — це баг, а не «рідкісна подія» |

## Симуляція (2000 забігів на стиль)

| Стиль гри | Днів (медіана) | Рішень | 
|---|---|---|
| «обізнаний» (Розуміння+Зв'язки) | 36 | 87 |
| «виживальник» (Здоров'я+Запаси) | 37 | 90 |
| «слідотворець» (шукає вчинки/навички) | 17 | 44 |
| випадковий | 28 | 68 |
| «конформіст» (Довіра) | 15 | 39 |

Конформізм і далі карається (15 днів проти 36). Усі 9 фіналів досяжні хоча б одним стилем: різні стилі помирають по-різному («обізнаний» частіше дістає «Добру пам'ять» і «Потім напишеш», «виживальник» — «Неліпу випадковість»).

## Наступні кроки

1. **Контент**: 76 → 120+ карток; у фазі 1 лише 9, у фазі 2 — 14.
2. **Баланс «слідотворця»**: він живе вдвічі менше за «обізнаного» — подивитись, чи це задум, чи наслідок цін.
3. **Метапрогресія й Книга пам'яті** (розділ 8 ТЗ) — `localStorage`, потім бекенд.
4. **Звук і тиша у фіналі**, локалізація EN.

## Свідомі обмеження

Немає метапрогресії, немає вагової кривої для персонажів (Толік, Оля, командир), немає EN. Реальні фото прибрано свідомо: вигадана історія не ілюструється кадрами реальної війни.
